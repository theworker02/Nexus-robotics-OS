# Nexus glossary

- **NCM** — Nexus Capability Model, the capability and provenance contract used by adapters and skills.
- **Nexus Brain** — Hardware-aware planning and profile guidance for compute and intelligence placement.
- **Model Fabric** — Provider-agnostic model configuration, routing, policy, and evaluation layer.
- **SenseHopping** — Selection and fallback across compatible physical or software sensing sources.
- **StructureScan** — Structured interpretation of observable environmental geometry and changes.
- **Active Learning** — Controlled, evidence-producing experiments that improve bounded behavior without weakening safety.
- **Proving Ground** — Validation framework that separates software, virtual hardware, physics, adversarial, HIL, and physical evidence.
- **Connected Intelligence** — External tools, MCP services, wireless devices, APIs, and edge systems connected through explicit permissions.
- **Safety Governor** — Deterministic authority that constrains, rejects, cancels, and monitors physical actions.
- **VirtualBus** — Software device and fault-injection surface for adapter and runtime testing without hardware.
