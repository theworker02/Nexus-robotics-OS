# Product Principles

## Hardware Agnostic

Nexus does not hard-code one robot model into its runtime.

## Capability Driven

Software asks what a robot can do, not what it is named.

## Simulation First

Major capabilities are testable before hardware is purchased.

## Safety First

Physical commands pass through the Safety Governor.

## Local First

Core control works without constant cloud connectivity.

## Observable

Meaningful actions have logs, events, telemetry, and replay entries.

## Reversible Where Possible

Actions can be stopped, and stateful execution is recorded for recovery.

## Developer Friendly

Skills use package-like manifests and compatibility checks.
