# Nori compatibility

Nexus provides a community-built compatibility layer for Nori-Lab-style training sessions, LeRobot-compatible datasets, Feetech MotorLab-style read-only diagnostics, and a Nori-style capability manifest. It does not modify upstream projects, claim an official relationship, or claim physical Nori validation.

Run `nexus compatibility inspect nori-a3` to inspect the simulated compatibility result. The Nori profile represents only the public configuration captured in `examples/robots/nori-a3.yaml`; undocumented hardware details are intentionally excluded.
