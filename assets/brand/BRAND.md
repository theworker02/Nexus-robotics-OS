# Nexus Robotics OS brand system

Nexus branding represents a physical machine connected through a unified software layer. The central node and modular arcs communicate interoperability, motion, and capability without using robot heads, brains, AI sparkles, or circuit-board imagery.

## Official assets

| Asset | Intended use |
| --- | --- |
| `horizontal.svg` | Default product lockup and README header. |
| `logo.svg` | Full dark-surface logo. |
| `mark.svg` | Compact application and product mark. |
| `wordmark.svg` | Text-only use where the mark is already visible. |
| `monochrome.svg` | One-color print and constrained surfaces. |
| `favicon.svg` | Browser and application icon. |
| `social-card.svg` / `github-banner.svg` | Social and repository presentation. |

## Visual language

- **Graphite** `#101827` is the primary structural color.
- **Precision blue** `#61A5FF` and `#2878E8` are accents for active, connected, and trusted operating states.
- **Off-white** `#F8FAFC` provides calm readable contrast.

The voice is industrial, premium, technical, and approachable. Avoid cyberpunk neon, military language, vendor imitation, or claims beyond documented validation.
